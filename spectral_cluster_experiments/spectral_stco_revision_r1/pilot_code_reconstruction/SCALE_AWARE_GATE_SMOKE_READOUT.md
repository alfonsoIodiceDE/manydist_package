# Exploratory Simulation 2 gated-method smoke check (2026-09-20)

This is a **six-dataset paired software/scientific pilot**, not a replacement
for either submitted simulation or evidence that the archived 50-replicate
table has been reproduced. It uses the previously saved n = 500 datasets
from `results/59e3500bd1/n0500/`: replicates 1–3 for each of the literal
and corrected-index reconstructions of the surviving `simulation xBIG.R`
generator. The two variants bracket an R index-precedence ambiguity in that
script. Base-R normal and fixed-size sample draws match its statistical
construction, not the unavailable SimDesign/sampling random streams. The
archived 50-replicate driver and package environment have not been recovered.

The no-interaction distance is **pure current manydist**:
`mdist(data, preset="custom", method_num="pc_scores", method_cat="tvd",
commensurable=FALSE, interaction=FALSE, ncomp=6)`. For each dataset, a
separate numeric-only package call obtains `D_num`, and the code verifies
`D_base = D_num + D_TVD` (largest decomposition error across the six datasets
was 1.7e-15). The interaction category-level deltas come from manydist's
`delta_int_knn`, with `prop_nn=0.10`, `score="ba"`, and
`decision="prior_corrected"`. A joint-categorical-row max-permutation gate
uses 99 permutations, family-wise alpha 0.01, and the same fixed gate seed
offset as the R1 pilot. For exploratory gamma values 0, 0.5, and 1, the
tested distance is

`D(gamma) = D_base + gamma * mean_upper(D_num) / q_cat * sum_j g_j Z_j Delta_int,j Z_j'`.

Thus gamma zero is exactly the package baseline, and the gate applies to
category-level deltas before their observation-level projection. Gamma 0.5
and 1 are **candidates, not selected or locked primary weights**. The
categorical TVD component is never reweighted or replaced by native
`mdist(interaction=TRUE)`. Gaussian affinity, known k=3, and the same spectral
clustering seed for all three arms were used on each dataset.

Mean paired ARI gain for gamma 1 was +0.00385 for the literal variant and
+0.00386 for the corrected variant. Four of six datasets gained, and two
lost slightly. The gate selected C1 and C2, and rejected nuisance C3 and C4,
in all six datasets. The gamma-1 added interaction term averaged 0.721
(literal) or 0.708 (corrected), versus mean numerical distance 5.111 or
5.093; the raw TVD block averaged 0.145 or 0.174. Consequently, the new
weight gives interaction a meaningful geometric contribution, but its ARI
effect on this tiny set remains modest and variable.

**Interpretation:** The direction is mildly positive, but this pilot does
not establish that the revised method reproduces the strong submitted
Simulation 2 result or consistently beats its exact no-interaction
ablation. Do not choose gamma by these six ARIs. Before a large run, resolve
the original-data provenance as far as possible, lock one method/weight and
evaluation plan, then run fresh paired Simulation 1 and 2 datasets plus a
matched no-interaction control. The extra control is proposed, not run here.

The immutable output sidecars are in `scale_aware_gate_smoke/59e3500bd1/n0500/`
and record source/data hashes, gate p-values, block means, and individual
ARIs. They were generated by `score_scale_aware_gate_smoke.R`. No original
simulation script, manuscript, saved result, or full-study manifest was
changed.
